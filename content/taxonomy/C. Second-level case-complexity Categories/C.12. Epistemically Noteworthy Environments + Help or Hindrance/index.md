id: C.12
title: Epistemically Noteworthy Environments + Help or Hindrance
---

When combining only the two complicating factors of {{< sc >}}Epistemically Noteworthy Environments{{< /sc >}} and {{< sc >}}Help or Hindrance{{< /sc >}}, it’s necessary for the {{< sc >}}Help or Hindrance{{< /sc >}} in question to be administered in the @-world as well as relevant modally close possible worlds to avoid inclusion of the additional complication of {{< sc >}}Counterfactual-Interference{{< /sc >}}. By combining an [Unfriendly Environment] or [Unfriendly Instruments Environment]{{< fn 1 "In this preliminary taxonomy, I don’t differentiate [case-types] in this complex {{< sc >}}Category{{< /sc >}} by whether the _unfriendly environment_ manifests as [Unfriendly Environment] or [Unfriendly Instruments Environment]. Separate [case-types] can (and should) be established _if_ x-phi results on tokens of the corresponding elementary [types] indicate different evaluation-behaviours." >}} with [Direct Cognitive Help], [Indirect Cognitive Help] or [Sensory Help], we can build scenarios in which the agent wouldn’t be fooled by misleading evidence present in their environment thanks to the _help_ administered to them. Through combination with [Indirect Cognitive Hindrance] or [Sensory Hindrance], we can build scenarios in which the agent is only at risk of being fooled by ‘misleading’ evidence _because_ of the _hindrance_ administered to them.{{< fn 2 "It’s possible to build versions which evoke [Sensory Hindrance] or [Indirect Cognitive Hindrance], because these allow for the possibility that S’s cognitive or sensory processes become less reliable, but S nevertheless gains a true belief (see B.6., [Insufficient Indirect Cognitive Hindrance] and [Insufficient Sensory Hindrance]). For [Direct Cognitive Hindrance], however, we can’t build a scenario where this kind of hindrance is administered in the @-world while the agent gains a true belief." >}}

Besides these combinations, I also consider [case-types] which combine [Unexpected Regularity Environment] with [Direct Cognitive Help] and [ Hindrance] respectively. I struggle, however, to identify distinct tokens of [case-types] that combine this environment with [Sensory Help] or [ Hindrance], or with [Indirect Cognitive Help] or [ Hindrance], however, other philosophers might be more creative.
