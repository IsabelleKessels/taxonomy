title: Counterfactual-Interfernce + Help or Hindrance
---

In elementary versions of {{< sc >}}Counterfactual-Interference{{< /sc >}} cases, S gains a true belief in the @-world and a false belief in modally close possible worlds. The elementary {{< sc >}}Help or Hindrance{{< /sc >}} [case-types] in which S gains a true belief include [Direct Cognitive Help], [Indirect Cognitive Help] and [Sensory Help]; the ones in which S gains a false belief include [Direct Cognitive Hindrance], [Indirect Cognitive Hindrance] and [Sensory Hindrance].{{< fn 1 "In what follows, I don’t consider combinations with [case-types] in which agents gain a false belief despite *help*, or where agents gain a true belief despite *hindrance*. If and when corresponding tokens find attention in the x-phi and armchair literature, respective [case-types] can (and should) be identified." >}} These are combinable with {{< sc >}}Counterfactual-Interference{{< /sc >}} in two ways:

- The counterfactual-interference would administer [Direct Cognitive Hindrance], [Indirect Cognitive Hindrance] or [Sensory Hindrance].
- [Direct Cognitive Help], [Indirect Cognitive Help] or [Sensory Help] is administered in the @-world, but a counterfactual-interference would prevent this the modally close possible worlds.
