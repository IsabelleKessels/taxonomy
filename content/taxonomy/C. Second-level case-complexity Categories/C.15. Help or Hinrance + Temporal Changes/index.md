title: Temporal Changes + Help or Hinrance
---

The elementary {{< sc >}}Category{{< /sc >}} of {{< sc >}}Help or Hindrance{{< /sc >}} already subsumes 13 distinct [case-types], so a complete overview on all of their possible combinations with Temporal Changes would be unwieldy. The examples below describe those involving elementary _help_-[case-types] in which the help results in S gaining a _true belief_ (without differentiation whether this manifests as [Direct Cognitive Help], [Indirect Cognitive Help] or [Sensory Help]) and elementary _hindrance_-[case-types] in which the hindrance results in S gaining a _false belief_ (without differentiation whether this manifests as [Direct Cognitive Hindrance], [Indirect Cognitive Hindrance] or [Sensory Hindrance]).{{< fn 1 "Separate [case-types] can (and should) be established *if* x-phi results on tokens of the corresponding elementary [types] indicate different evaluation-behaviours." >}}
