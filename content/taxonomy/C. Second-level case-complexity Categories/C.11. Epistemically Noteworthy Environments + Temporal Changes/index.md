title: Epistemically Noteworthy Environments + Temporal Changes
---

{{< sc >}}Epistemically Noteworthy Environments{{< /sc >}} comprise _unfriendly_ and _unexpected regularity_ environments. In my overview below, I focus only on the combination of {{< sc >}}Temporal Changes{{< /sc >}} with [Unfriendly Environment] and [Unfriendly Instruments Environment]. In [Unfriendly Environment] scenarios, the agent’s belief is true. This restriction acknowledged, the table below identifies which {{< sc >}}Temporal Changes{{< /sc >}} could incorporate an [Unfriendly Environment] to implement {{< sc >}}Epistemically Noteworthy Environments{{< /sc >}} as a complicating factor.{{< fn 1 "In this preliminary taxonomy, I don’t differentiate [case-types] in this complex {{< sc >}}Category{{< /sc >}} by whether the _unfriendly environment_ manifests as [Unfriendly Environment] or [Unfriendly Instruments Environment]. Separate [case-types] can (and should) be established _if_ x-phi results on tokens of the corresponding elementary [types] indicate different evaluation-behaviours." >}} I deprioritise the combination of {{< sc >}}Temporal Changes{{< /sc >}} with [Unexpected Regularity Environment] because the latter amounts to interesting [case-types] only when further combined with {{< sc >}}Testimony, Standard Gettier{{< /sc >}} and/or {{< sc >}}Help or Hindrance{{< /sc >}}: An [Unexpected Regularity Environment] scenario at time t~~n~~, without another complicating factor which impacts what’s happening in the @ world or modally close possible worlds, just is an instance of S forming no belief about p, despite being justified to infer that p if they were aware of their environment’s regularity.
