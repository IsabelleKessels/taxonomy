title: Truth From False Premise + Temporal Changes
---

An agent _can’t believe the truth from a false premise_ if the belief they hold is _false_. This restriction acknowledged, the table below identifies which {{< sc >}}Temporal Changes{{< /sc >}} could incorporate {{< sc >}}Truth From False Premise{{< /sc >}} as a complicating factor. I concentrate on identifying [case-types] where this is implemented as _gettering_, rather than ‘Knowledge From Falsehood’.{{< fn 1 "In this preliminary taxonomy, I don’t differentiate [case-types] in this complex {{< sc >}}Category{{< /sc >}} by whether the _gettiering_ manifests as [Direct Gettier], [False Premise Gettier] or [Instrument Gettier], apart from one specific instrument variant: [Change of Truth Value, Basis for Belief & Doxastic Attitude: Reliable Instrument Calibrated to Gettier]. Separate [case types] can (and should) be established _if_ x-phi results on tokens of the corresponding elementary [types] indicate different evaluation-behaviours." >}} There is one exception, namely [Change of Basis for Belief: Paradigmatic Knowledge to Knowledge From Falsehood]; I include this [case-type], because I’m aware of a relevant case-token in the literature on ‘Knowledge From Falsehood’ that needs to be demarcated form tokens of the first-level complexity [Knowledge From Falsehood].
