title: Counterfactual-Interfernce + Temporal Changes

In elementary {{< sc >}}Counterfactual-Interference{{< /sc >}} cases, S gains a true belief in the @-world; consequently, this complicating factor can’t apply when the agent’s belief is false in the @-world. With this restriction acknowledge, the table below identifies which {{< sc >}}Temporal Changes{{< /sc >}} could incorporate {{< sc >}}Counterfactual-Interference{{< /sc >}} as a complicating factor.{{< fn 1 "In this preliminary taxonomy, I don’t differentiate [case-types] in this complex {{< sc >}}Category{{< /sc >}} by whether the {{< sc >}}Counterfactual-Interference{{< /sc >}} manifests as [Counterfactual-Interference in Modally Close non-p-Worlds], [Counterfactual-Interference in Modally Close p-Worlds], [Instrument Counterfactual-Interference in Modally Close non-p-Worlds] or [Instrument Counterfactual-Interference in Modally Close p-Worlds]. Separate [case-types] can (and should) be established _if_ x-phi results on tokens of the corresponding elementary [types] indicate different evaluation-behaviours." >}}
