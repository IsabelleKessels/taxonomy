title: Elementary Categories
---

I propose the following six {{< sc >}}Categories{{< /sc >}} as elementary to any taxonomy of thought experiments on propositional knowledge. Not all of these subsume thought experiments explicitly represented as counterexamples in the literature; yet, each represents a complicating factor found in complex {{< sc >}}Categories{{< /sc >}}, which do subsume thought experiments levered as counterexamples.
